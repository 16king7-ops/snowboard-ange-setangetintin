左右どちらの足が前か迷ったら C

決め方には「ボールを蹴る足を後ろ」「押されて出た足を前」など結論が逆になる説が並んでいて、確立した判定法はない。次の違和感があれば、緩斜面で逆向きを試す価値がある。

  • 進行方向（谷側）を見るのに、首をかなり無理にひねる必要がある
  • トゥサイドとヒールサイドの上達の差が極端に大きい
  • 何も考えずに立つと、逆向きになっている

逆向きにすると前後の足が入れ替わり、図のノーズの向きも反対になる。

角度とブーツのはみ出し（ドラグ）

深く傾けたとき、板からはみ出したブーツのつま先やかかとが雪に触れると、板がテコで持ち上げられてエッジが抜ける A。足の角度をつけるほどブーツが斜めになり、はみ出しは減る A。はみ出しの目安は各エッジ1〜2cm以内 B。

今の前足の位置で計算。ブーツ外寸と底の高さは推定 C。エッジ角30〜45°のターンなら、どの角度でも触れない。

エッジ角とターンの物理（計算で見る） A

板を傾けた角度から、ターンの大きさ・必要なたわみ・速度・板にかかる力を理想化して計算します。前傾の説明は「道具」タブの表にあります。

セッティングを決める順番

  1. 向きを決める: レギュラー（左足が前）かグーフィー（右足が前）。
  2. 目的でプリセットを選ぶ: S字練習 / ラントリ / グラトリ。理由は「理由」タブ。
  3. 体に合わせる: 下の床テストで、膝の向き・かかと・腰を確認し、角度と幅を1つずつ直す。
  4. 取り付ける: 下の手順。ネジ穴・ディスクの溝・つま先とかかとのバランス。
  5. バインディングとブーツを合わせる: トゥランプ・ストラップ・前傾・BOA（「道具」タブ）。
  6. 滑って直す: 1回に1か所。変えたら「記録」タブに残す。

迷ったら「体に合うこと（しゃがんだとき膝がつま先の方向に出る）」を最優先。次に目的、最後に好み。

床テスト（取り付ける前に） B

膝はつま先と同じ方向に曲げるのが、膝をねじらない基本の形。ビンディングでつま先の向きを固定しているのに、股関節がその方向に開かないと、しゃがんだ瞬間に膝が内側に入ってねじれやすい。これが「疲れる」「板を踏めない」「膝が痛い」の原因になりやすい。

  1. 床にマスキングテープで、上の間隔と角度の足形を貼る。
  2. 足形の上に立ち、深くしゃがむ。つま先側・かかと側へ体重を移してみる。
  3. 下の3つを確認する。NGがあれば、1つだけ直してもう一度しゃがむ。
確認することNGのとき調整
膝がつま先と同じ方向に出ているか膝が内側に入るその足の角度を0°側へ3°戻す
かかとが浮かないか浮く（足首が硬い / 幅が広すぎ）幅を2cm狭く（1穴内側）。取り付けたあと滑っていて浮くなら、前傾を弱くするのも試す
腰がねじれてしんどくないかしんどい（後足のマイナスが深すぎ）後足を+3°（マイナスを浅く）

足首が硬い・股関節が開きにくいと感じたら、角度を変えるだけでなく、フォーム分析アプリの「🏋️ オフトレ」（足首ストレッチなど）も続けると体が合わせやすくなる B。

取り付け手順 今の設定の値が入る

SALOMON RHYTHM（バインディング）

位置づけ
上達を助けるための、柔らかめで扱いやすいモデル（公式の表記は「ソフト」、海外の販売店は「ミディアムソフト」）。上位モデルにあるヒールカップの構造「Shadow Fit」は付いていない。
非対称の形
ハイバックとベースプレートが左右非対称。足の外側はしっかり支え、内側はしなるので、局所的に当たって痛くなりにくい（メーカー説明）。
ハイバック
最初から12°ひねった形。後から回して向きを変えられるかは公表情報では確認できないので、実物で確認する C。
フットベッド
2.5°の傾き（カント）付きのEVAクッション。メーカーは「弾きとエッジコントロールを高める」と説明。一般には、脚を開いて立つ形に足裏を合わせて膝の負担を減らすための構造 B。
ベース
コンポジット（樹脂系）。アルミより快適で耐久性が高いというメーカー説明。
ディスク
ユニバーサルディスク。4x4・2x4・3D・チャンネルの板に取り付けられる。目盛りは3°刻みが一般的だが、RHYTHMの刻みは公表情報にないので実物で確認 C。
サイズ
サロモン日本公式ではMが26.5〜27.5cm（年式や国で表が違い、海外の販売店はUS6.5〜10）。27.5cmは日本公式の表では上限なので、ブーツがきちんと収まるか、ストラップの長さに余裕があるかを確認する B。

SALOMON FACTION BOA（ブーツ）

硬さ
柔らかめ（販売店の説明は「ソフトフレックス」）。足首を曲げやすく、プレスや低速のターンで扱いやすい。代わりに高速では支えが弱い B。
BOA（ダイヤル1つ）
H4 Coiler。ダイヤルを押し込んで回すと締まる。ダイヤル1つでブーツ全体を締める方式なので、足首と甲で締め具合を分けられない。
ライナー
熱成形に対応したUltralonフォーム（販売店の説明）。ライナーを温めて履き、滑る姿勢で形をなじませる。サイズが合わないのを直すものではないので、初めてならショップに頼む B。
ソール
D-Light（EVA）。軽くて薄く、溝のパターンでグリップと衝撃吸収（メーカー説明）。FTR構造で外寸が約10%コンパクトなので、はみ出しが少なくなる方向。

調整のルール

  • 1回に変えるのは1か所だけ。2か所同時に変えると、どちらが効いたか分からなくなる。
  • 変える単位: 角度は3°（ディスクの1目盛り）、幅は2cm（片足を1穴）、前傾は1段。
  • 進める順番（目安）: S字練習 → スイッチを始めたら後足−9° → プレス・オーリーを始めたら幅54cm → 56cm → スピードを上げてヒールサイドが抜けるなら前傾1段（＝ラントリ）。グラトリはその後。いつ進むかは「上達」タブ。
  • スマホでも使える: 公開したページをスマホで開き、ホーム画面に追加すると、電波がない所でも開ける。PCとのデータの受け渡しはこのタブの下の「PCとスマホでデータを共有」。
  • 判断は同じ条件で: 雪の状態や疲れで感覚は変わるので、変えた直後の1本で決めず、何本か滑ってから記録する。
